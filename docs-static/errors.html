Errors

Every Delivrie API error, what causes it and how to fix it, with the JSON error format and which errors are safe to retry.

Errors use standard HTTP status codes and a JSON body:

{
  "statusCode": 422,
  "name": "validation_error",
  "message": "The from domain mail.acme.com is not verified yet (status: pending)."
}

Branch on name in code and show message to people: it's written to say exactly what went wrong. Every request, including failed ones, appears in Logs with its request and response bodies.

Retrying

Retry 5xx errors and network failures with the same Idempotency-Key. Don't retry 4xx errors, including quota 429s; they won't succeed until something changes. See Idempotency and retries.

Errors in the SDK

The Node.js SDK returns errors instead of throwing: const { data, error } = await delivrie.emails.send(...). error has the same statusCode, name and message. Problems that never reach the API have statusCode: 0 and the name network_error, timeout or aborted.
