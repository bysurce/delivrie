Create automation

POST /automations

Create a straight-line automation: a trigger and up to 30 send and wait steps. Build branches and conditions in the dashboard.

FieldTypeDescription
namestringrequiredName.
triggerobjectrequired{ "event": "user.created" } or { "segment_id": "…" }.
stepsobject[]required{ "type": "send", "template_id": "alias" } or { "type": "wait", "amount": 2, "unit": "days" }. Units: minutes, hours, days, weeks.
reentrystringonce or always.
publishbooleanPublish right away.
